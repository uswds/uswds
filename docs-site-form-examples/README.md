# Documentation form error examples

Component preview fragments rendered with the installed USWDS site dependency. These show the existing default examples together with newly documented error states. They are state comparisons, not evidence of runtime bug fixes. The input-mask defaults remain those in the pinned dependency; the new alphanumeric error hint matches proposed core PR #6953.

The browser check verified unique IDs, description targets, error markup preservation after enhancement, and absence of page errors. Screen-reader speech was not tested. Full page layout is outside these captures.
